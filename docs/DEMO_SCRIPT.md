## 🎨 Production Notes & Asset Checklist

### 1. Screen Recording Settings
- **Resolution:** 3840 x 2160 (4K), rendered at 60 FPS.
- **Display Scaling:** 125% Windows DPI for optimal legibility of code and UI fonts.
- **Theme:** Windows 11 Dark Mode, Mica material transparency active.

### 2. Audio Specs
- **Voiceover Artist:** Clear, articulate baritone or neutral mid-range voice. No vocal fry. Crisp high-end presence.
- **Sample Rate:** 48 kHz / 24-bit WAV.
- **Mix Balance:** Voiceover peaked at -6 dB; music ducked to -18 dB during spoken segments and swelling to -10 dB in transitions.

### 3. Key Callouts for Motion Graphics
- Animated cold-start timer (`0ms` ➔ `56ms`).
- RRF Score badge (`0.94`) highlighting sqlite-vec hybrid memory recall.
- WinGet copy command box with green checkmark feedback.
