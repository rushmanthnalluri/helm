What is in the source

These are implementation areas, not a release acceptance report. Windows compatibility and end-to-end product measurements are still pending.

🎙️

Voice components

The repository contains optional speech and text-to-speech integrations. The default dictation path uses local Whisper; optional stacks are not required for the core build.

⚡

Local caret dictation path

The desktop path captures speech, transcribes locally, and sends Unicode keyboard input without using the clipboard. Physical compatibility acceptance remains pending.

🔍

Desktop Omnibar

The source includes a Windows shortcut, window and app search, and fuzzy matching. No published latency measurements are available.

🪪

Consequential-action approvals

Approval behavior depends on the route. The broker may request Windows Hello; supervisor-protected actions separately require an enrolled-device signature.

🧠

Local memory components

The repository includes SQLite-backed memory and optional vector-search components. Some memory and search features require optional dependencies.

🌐

Browser integration

Optional browser tools support selected browser workflows. Availability and permissions depend on the local configuration.

Where data goes

Dictation is local by default. Cloud AI and connected integrations send data to their selected services.

Data path Default behavior What leaves the device
Caret dictation Local Whisper by default Audio stays on-device. The model downloads on first use.
Talk to Helm Local Whisper; cloud speech fallback off If `speechCloudFallback` is enabled and local transcription fails, audio goes to Google Speech Recognition.
AI chat Local offline mode or selected provider When a cloud provider is selected, prompts and included context go to that provider.
Connected integrations Run when invoked Requests and selected data go to the integration's service.
